# Contributing to Screen Monitor OS

First off, thank you for considering contributing to Screen Monitor OS! It's people like you that make the open-source community such a fantastic place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an issue on GitHub. Include as much detail as possible:
* **Your Operating System** (Windows, macOS, Linux) and version.
* **Python version** (`python --version`).
* **Steps to reproduce** the behavior.
* What you expected to happen vs. what actually happened.
* Any error messages or tracebacks from the terminal.

### Suggesting Enhancements
We welcome new features! If you have an idea to improve the application:
1. Open an issue describing your proposed feature.
2. Explain why this enhancement would be useful to most users.
3. If you'd like to build it yourself, let us know in the issue so we can assign it to you.

### Pull Requests
Ready to write some code? Great!
1. **Fork** the repository and clone your fork locally.
2. **Create a branch** for your feature or bugfix (`git checkout -b feature/amazing-feature`).
3. **Commit** your changes with clear, descriptive messages (`git commit -m "Add new theme options"`).
4. **Push** your branch to your fork (`git push origin feature/amazing-feature`).
5. **Open a Pull Request** against the `main` branch of this repository.

## Development Guidelines
* **Dependencies:** Try to rely on standard Python libraries wherever possible to keep the tool lightweight. If adding a new external dependency, please explain why it is necessary in your PR.
* **Code Style:** Keep the code clean and well-commented. Try to follow standard PEP 8 guidelines for Python.
* **Testing:** Test your changes locally to ensure the UI still renders correctly and the application gracefully closes on your OS.

Thank you for your contributions!
